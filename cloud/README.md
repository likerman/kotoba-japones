# Kotoba Cloud

Versión con perfiles compartidos, estadísticas por tema y competición amistosa.

- `src/data.ts`: contenido de las Lecciones 1–5.
- `src/main.ts`: entrenamiento, perfiles y carrera.
- `backend/index.ts`: API y persistencia de resultados.
- `tests/tests.json`: recorridos funcionales de publicación.

Los perfiles familiares no tienen autenticación ni almacenan datos sensibles.
